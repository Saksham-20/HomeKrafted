# Seller Dashboard Guide

Purpose: this is the day-to-day operating guide for HomeKrafters using the seller portal.

## Access and role behavior

- Seller portal root: /seller
- Sign-in: /login
- After sign-in, seller accounts land on /seller.
- Seller accounts can also shop on the consumer surface using Switch to shopping.

## Seller navigation map

Current shared seller nav:

- Dashboard: /seller
- Analytics: /seller/analytics
- Listings: /seller/listings
- Menu: /seller/menu
- Meal plans: /seller/meal-plans
- Orders: /seller/orders
- Storefront: /seller/storefront
- Profile: /seller/profile
- Payouts: /seller/payouts
- Reviews: /seller/reviews

Notes:

- All HomeKrafters see the same unified nav.
- If you do not use a module yet, that module should show an empty state rather than be hidden.

## Daily workflow (recommended)

1. Check Dashboard for today signals and pending items.
2. Open Orders to process active fulfillment first.
3. Update Listings/Menu availability and stock-sensitive items.
4. Review Meal plans deliveries due today.
5. Check Reviews and reply where needed.
6. Confirm payout status and pending amounts.

## Route-by-route operations

### Dashboard (/seller)

Use this for quick health:

- Today activity snapshot.
- Pending actions and shortcuts.
- Operational signals before opening deeper modules.

### Listings (/seller/listings)

Use for product catalog management:

- Add/edit listing details.
- Toggle item availability.
- Keep names, photos, and descriptions accurate.

Best practice:

- Treat listing edits as merchandising and trust updates; keep storefront copy current.

### Menu (/seller/menu)

Use for snacks-specific items:

- Create/edit snack menu entries.
- Manage price and available status.

### Meal plans (/seller/meal-plans)

Use for subscription offerings:

- Create and manage meal plans.
- Track owed deliveries and upcoming commitments.

### Orders (/seller/orders)

Use for fulfillment progression:

- Move order status through valid sequence.
- Confirm each transition carefully before advancing.

### Storefront (/seller/storefront)

Use for public-facing storefront identity:

- Storefront fields shown to buyers in listing contexts.
- Keep core brand identity and discoverability details sharp.

### Profile (/seller/profile)

Use for trust and depth details:

- Story, hours, and policies.
- Information buyers review before placing trust.

### Reviews (/seller/reviews)

Use for buyer confidence loop:

- Read product/storefront feedback.
- Post clear and timely replies.

### Analytics (/seller/analytics)

Use for performance decisions:

- What sells, trends over time, and operational opportunities.
- Prioritize actions based on actual movement, not assumptions.

### Payouts (/seller/payouts)

Use for settlement tracking:

- Monitor pending vs paid payouts.
- Reconcile expected payout amounts with order activity.

## First-week setup checklist for new HomeKrafters

1. Complete Storefront and Profile.
2. Add initial listings/menu items with clean photos.
3. Verify at least one active offer is purchasable.
4. Learn Orders status updates before first live fulfillment.
5. Check Reviews and Payouts screens to understand feedback and cash flow.

## Troubleshooting

- Cannot access seller routes after sign-in:
  - Confirm account role is seller and sign-in completed.
  - If redirected to set password, complete /set-password first.
- Missing expected data:
  - Confirm you are in the correct module and item ownership scope.
  - New accounts may legitimately see empty states.
- Need buyer-side view:
  - Use Switch to shopping and open your storefront from the consumer side.
